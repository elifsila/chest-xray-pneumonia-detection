# Trained Model Weights

Model weights are not stored in this repository because the trained `.keras` files exceed GitHub's 100 MB file size limit.

All trained model weights can be downloaded from Google Drive:

[Download Models from Google Drive](https://drive.google.com/drive/folders/1L-NEQPg3l8lk5-76ynJloCeIzsnakoEf?usp=sharing)

## Files

| File | Size | Description |
|------|------|-------------|
| custom_cnn.keras | ~51 MB | Custom CNN model weights |
| efficientnet.keras | ~48 MB | EfficientNetB0 model weights |
| resnet50.keras | ~207 MB | ResNet50 model weights |

## Note

All models can be reproduced by running the notebook `chest-xray-pneumonia-detection.ipynb` from scratch.
